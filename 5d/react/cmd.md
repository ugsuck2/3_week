### CRA 프로젝트 생성

npx create-react-app 프로젝트명

### CRA 프로젝트 실행
해당 경로로 이동
npm start
or
npm run start


### VITE 프로젝트 생성
npm create vite@latest 프로젝트명

옵션.
React
Javascript
Eslint

### VITE 프로젝트 실행
해당 프로젝트 경로로 이동
npm run dev

### node_modules 폴더가 존재하지 않는경우.
해당 프로젝트 경로에서 package.json 파일 존재 확인
npm install

### 실행중인 서버 종료
Ctrl + C
